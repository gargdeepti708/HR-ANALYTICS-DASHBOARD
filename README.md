# HR Analytics Dashboard 📊

An interactive **HR Analytics Dashboard** created using **Power BI** to analyze employee data and provide meaningful insights into workforce trends.

## 🔍 Key Insights

* Total Employee Count
* Attrition Count & Attrition Rate
* Average Employee Age
* Average Salary
* Average Years of Experience
* Attrition by Age Group
* Attrition by Education
* Attrition by Salary Slab
* Attrition by Job Role
* Employee distribution across different categories

## 🛠️ Tools & Technologies

* **Power BI**
* **DAX**
* **Power Query**
* **Data Visualization**
* **Data Cleaning & Transformation**

## 📌 Dashboard Features

The dashboard includes interactive visuals, KPI cards, charts, and filters to help understand employee demographics, salary distribution, and attrition patterns.

This project was created as a **Data Analytics portfolio project** to practice data cleaning, DAX calculations, data visualization, and dashboard development using Power BI.
